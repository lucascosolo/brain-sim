# P2-R1: feedback writer identity helps, but does not repair the index

Measured 2026-10-12 under contract `8002427`, driver `8b7c062`.
This is a reported diagnostic with two predeclared exploratory seeds, not a new gated PASS.
Both mandatory runs completed; optional seeds 45 and 91 were not spent.

## Fixed-readout results

Content joint means missing-feature recall and intrusion requirements on the same half cue,
within the inherited 75 ms window. Index C1 and C2 use their separate 50 ms window.
All five writers in each row use the identical memory raster.

Each fraction uses 200 half cues. The oldest 100 correlated items still have index specificity
.84 at 500 and .40 at 1000. Thus even the favorable 500-item content replay does not meet the
complete inherited index contract. Duty 1000 oldest content is .19 for R1 and 1.00 for R3/A.
All predeclared numerical predictions were met on these two exploratory reproductions.

R3 identifies the externally assigned plateau key extremely well: at 1000 items its micro
precision/recall are .9975/.9657 (correlated) and .9986/.9997 (duty). Its average writer count
is 19.236 and 20.108, respectively. Matching that count with random or anti-selected responders
does not reproduce the duty result. Writer identity matters beyond the number of writers.
This is evidence for recovering an assigned key from activity, not selecting an autonomous
representation. Assigned A is a comparator, not a mathematical optimum; R3 can exceed it.

## What was separated, and what was not

- **Index interference:** unchanged by every feedback swap. At F10/1000, C2=.50 and both A/R3
  content remain far below .90. Cleaning the tested feedback store cannot close this case.
- **Feedback contamination:** a direct matched-raster intervention supports a large effect in
  duty/1000 (.205 to .995). The random control reaches .710, so part of the gain can come from
  sparsity while the remainder depends on which observed responders write.
- **Online operating state:** only the inherited store was read live. At duty/1000 live content
  joint=.545 and joint memory-recall-plus-content=.510. R3's .995 was obtained after settling
  a copied network. It does not demonstrate live access, online R3 coordination or O4/O5 repair.
- **Habituation/recovery:** not newly measured by this replay. Historical composite labels
  depend on content as well as index; feedback changes cannot be declared irrelevant to them.
- **Capacity:** this supplies two fixed-size load checkpoints, not capacity growth, a saturation
  law or graceful forgetting. Statistical overlap, age and operating state remain interacting
  explanations. The interventions do not establish an additive decomposition of failure.

Frozen deployed readout remains primary. No threshold grid was used to improve these numbers.
No change to E1–E5 verdicts, Stage 1 status, or the simulated system's deployed capability follows.

## Evidence and reproduction

`bench/results/p2r1.jsonl` retains starts, individual load results and completions.
`bench/results/p2r1/` contains portable per-cue counters and latencies, sufficient to recompute
the reported aggregates. Each record hashes its compressed raw replay artifact under
`~/.cache/brain-sim/plant2/p2r1/`; these large rasters/stores are local cache artifacts, not Git
backups. They can be regenerated by the commands below. Historical raw caches were absent;
the separate baseline audit validates committed aggregates, not missing historical raw traces.

```bash
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python3 -u -m analysis.p2r1_replay --regime correlated --seed 44 --run-id YOUR_NEW_RUN_ID
PYTHONDONTWRITEBYTECODE=1 OPENBLAS_NUM_THREADS=1 python3 -u -m analysis.p2r1_replay --regime duty --seed 90 --run-id YOUR_OTHER_NEW_RUN_ID
```

Use fresh run IDs; never overwrite or erase a run. Runtime: Python 3.12.14, NumPy 2.3.5.
Correlated run completed in about 123 s; duty run in 247 s. Cross-runtime bit identity with
historical exploratory runs is not assumed. Six replay integrity tests pass, including exact
writer sizes and inherited union equality. The independent code reviewer verified raw reload
on a small network; the results methodology review is retained separately under `review/plant2/P2-R1/`.

The next primary experiment is the separately frozen P2-E6 presynaptic-load encoding rule.

## Independent results review closure

The independent reviewer recomputed 718 aggregate comparisons and all 15,000 saved writer
selections, and verified four compact plus four raw artifact hashes. No correctness blocker
was found. Six scope findings were accepted in the ledger. These reused seeds provide no new
across-seed generalization evidence; R3 is not an itemwise monotonic repair (at correlated
1000 it wins 32 cues and loses two against R1). The supplementary out-of-window spike count
requires raw dynamics replay; portable evidence covers the required criterion aggregates.
